# Attribution

The subsets `noul`, `choice`, `score` and `all` of this repository are a collection released under
**CC BY-SA 4.0** (`CC-BY-SA-4.0.txt`). The collection includes the datasets below. Each dataset keeps
its own license and attribution requirements; the collection license does not remove them.
License texts: `CC-BY-SA-4.0.txt`, `CC-BY-4.0.txt`, `MIT.txt`, `Apache-2.0.txt`.

## Changes made

Rows were converted, without changing the upstream content, into one common schema
(`id`, `primitive`, `dataset_id`, `source_dataset`, `source_repo`, `source_url`, `source_split`,
`source_license`, `question`, `options`, `gold_index`, `metadata`) by the adapters of
[jev-ja-lab](https://github.com/hachiko85/jev-ja-lab):

- The question text and answer options are assembled from the upstream fields (for example a Noul
  question is built from a premise and a hypothesis, a Score question from a text and a rubric).
- Choice datasets derived from numeric answers (`gsm8k_ja_mc4`, `gsm8k_ja_mc10`, `mgsm_ja`) add
  generated distractor options (seed 42). The correct answer is the upstream answer.
- Splits: validation / valid splits of the upstream are stored as `test`; the original split is
  kept in `source_split`.
- HelpSteer2-JA benchmark-v1 is a 2,500-row extract (see `helpsteer2_ja/benchmark-v1.manifest.json`)
  and each of its five axes is one Score dataset.
